## Title

Visible bird migration counts at Défilé de l’Écluse, France, since 1966

## Description

Visible bird migration counts from Défilé de l’Écluse, France, since 1966, harmonised from historical records and recent Trektellen exports. Three linked tables describe recorded bird quantities or presence, survey intervals and a curated taxonomic reference; accompanying guides explain their fields and use.

Coverage, recording methods and taxonomic scope vary over time. Missing records do not imply absence, and only main-direction counts should be used for migration totals. Detailed methods and limitations are described in the accompanying data paper (in preparation); meanwhile, see the [project repository and documentation](https://github.com/Rafnuss/defile-dataset).
